Design system

Tokyo Paper

A human-centric design system in plain HTML and CSS. Each page shows a component’s markup, variants and states in both themes.

Actions and forms

Button

Primary, ghost, quiet and icon buttons, with disabled and busy states.

Field

Text input, textarea and select, with hints and errors.

Checkbox and radio

Pick any number of options, or exactly one.

Switch

Settings that apply immediately.

Content

Card

Group related content; optionally clickable as a whole.

Pill

Small labels for status and metadata.

Stat

Key numbers at a glance.

Table

Sortable, selectable data with sticky headers.

Code

Code blocks with Tokyo Night syntax colors and copy.

Empty state

What goes here, and one clear next step.

Feedback and overlays

Alert

Inline messages and app-wide banners.

Toast

Brief confirmation of an action, with Undo.

Dialog

Decisions that must be made before continuing.

Menu

A short list of actions from a button.

Navigation

Navigation

Top bar, skip link and mobile menu sheet.

Tabs

Switch between views of the same content.
